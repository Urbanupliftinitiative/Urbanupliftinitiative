# Urban Uplift Initiative

Website for Urban Uplift Initiative Community Development — a faith-based community nonprofit in Camden, NJ running a youth mentorship program and community-development initiatives (senior safety, back-to-school breakfast, and more).

## Stack

- React (Create React App via [craco](https://craco.js.org/))
- React Router
- Tailwind CSS
- Framer Motion

## Development

```bash
cd frontend
npm install
npm start
```

## Build

```bash
cd frontend
npm run build
```
